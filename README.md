# FleetBreak ⚓

**FleetBreak** — современная браузерная версия «Морского боя», созданная для второго технического этапа **Narxoz Incubator 2026**.

> **10 минут. Два флота. Один победитель.**

## Для кого продукт

Для студентов и молодых пользователей, которым нужна короткая интеллектуальная игра без регистрации, установки и долгого обучения.

## Реализованный функционал

- полноценная партия от расстановки до победы/поражения;
- поле 10×10;
- классический флот: 1×4, 2×3, 3×2, 4×1;
- ручная и автоматическая расстановка;
- запрет пересечения и соприкосновения кораблей;
- попадания, промахи и потопления;
- запрет повторных выстрелов;
- корректное определение победителя;
- новая игра;
- 3 сложности компьютерного соперника;
- сохранение текущей партии в `LocalStorage`;
- история матчей и статистика;
- адаптивный интерфейс для телефона;
- **Battle Analysis** после завершения партии.

## AI-соперник

### Easy — Новичок
Стреляет по случайным неиспользованным клеткам.

### Medium — Тактик
После попадания проверяет соседние клетки.

### Hard — Адмирал
Использует вероятностную карту возможного расположения оставшихся кораблей. После нескольких попаданий по одному кораблю продолжает поиск по его линии.

**Важно:** AI не читает скрытые координаты кораблей игрока. Для выбора хода он использует только историю своих выстрелов.

## Правила FleetBreak

- поле 10×10;
- 10 кораблей / 20 палуб;
- размещение горизонтальное или вертикальное;
- корабли не могут соприкасаться даже углами;
- игрок и AI делают по одному выстрелу за ход;
- попадание не даёт дополнительный ход;
- побеждает тот, кто первым уничтожил весь флот.

## Battle Analysis

После матча приложение показывает:

- число выстрелов;
- попадания;
- точность;
- уровень сложности;
- краткие рекомендации по поиску и добиванию кораблей.

Разбор основан на истории ходов и работает локально.

## Технологии

Production-версия намеренно сделана без build-step:

- HTML5
- CSS3
- JavaScript (ES2020+)
- LocalStorage

Это уменьшает количество внешних зависимостей и позволяет развернуть проект на любом статическом хостинге.

## Запуск

Локально достаточно открыть `index.html`.

Для полноценного тестирования `LocalStorage` рекомендуется поднять статический сервер:

```bash
python -m http.server 8080
```

После этого открыть:

```text
http://localhost:8080
```

## Деплой

## Известные ограничения

- нет онлайн-мультиплеера;
- нет облачной авторизации;
- статистика хранится только в текущем браузере;
- Battle Analysis работает на правилах/метриках, а не на LLM.
